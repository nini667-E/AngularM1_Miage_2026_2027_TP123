## Objectif

À partir du TP4, vous démarrez votre mini projet. Vous êtes plus « libres »
d'orienter le projet.

## Point de départ

Réfléchissez à ce que vous pouvez faire à partir du prototype actuel, qui
comprend :

- la gestion des utilisateurs ;
- la manipulation / l'upload / le download de fichiers, et d'autres données
  de formulaire.

## Orientations possibles

Vous pouvez :

- faire un mini réseau social de partage de fichiers multimédia ;
- faire une application « solo » avec des fichiers publics et privés, un
  petit moteur de recherche, etc. ;
- faire une application orientée musique (la spécialité de l'enseignant).

## Fichiers publics / privés

Pour du partage entre utilisateurs :

- un fichier **public** peut être recherché et trouvé par tout le monde ;
- afficher quelque part les « **fichiers récemment ajoutés** » ;
- un fichier peut aussi être **privé** :
  - et on peut le partager avec des « **amis** » ;
  - donc il faut des fonctionnalités de réseau social : inviter / ajouter /
    supprimer des amis, voir l'activité des amis, etc. ;
  - gestion du partage : on veut pouvoir **stopper un partage** ;
- il faut un « **search files** » (recherche de fichiers).

## Démarche avec l'assistant IA

Avant de commencer l'implémentation, discutez avec votre assistant IA des
points suivants :

1. **Les fonctionnalités souhaitées** : définissez ce que vous aimeriez
   réaliser.
2. **Les interfaces utilisateur proposées** : examinez les différentes
   possibilités d'interface (UI).
3. **L'implémentation** : discutez des choix techniques et de la manière de
   procéder.
4. **Le découpage du travail** : divisez l'implémentation en plusieurs
   tâches, missions ou étapes, puis commencez par réaliser la première.

## Tests

Demandez également à votre assistant IA d'ajouter des **tests unitaires
pour toutes les nouvelles fonctionnalités**, afin de vérifier leur bon
fonctionnement.

## Livrable : `REPORT.md`

Enfin, demandez-lui de rédiger un rapport dans un fichier `REPORT.md`,
décrivant :

- le travail effectué ;
- les choix techniques ;
- les fonctionnalités implémentées ;
- les résultats des tests.
