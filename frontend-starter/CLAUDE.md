# Claude instructions

Follow `AGENTS.md` and `best-practices.md`. This project uses Angular 22 standalone components, `inject()`, Signals, Reactive Forms, and native `@if`/`@for` control flow. Preserve `API_CONTRACT.md` and keep shared infrastructure in `src/app/shared`. Since the V2 mini project (TP4-TP6, see `../SUJET_ETUDIANT_TP456.md` and `../REPORT.md`), `backend/` may be modified when a feature needs it. Any new or changed API route must update `API_CONTRACT.md` in the same change with its method, URL, auth, parameters, body, responses, and errors. Every new feature ships with unit tests (backend and frontend).
